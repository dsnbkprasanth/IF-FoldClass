# IF-FoldClass

Cell-derived calibration of AlphaMissense for desmin filament-assembly variants.

Two-stage LightGBM pipeline stacked with ESM-2 (t33-650M / UR50D):
- **Stage A** — pathogenicity across 20 intermediate-filament (IF) genes (ClinVar/gnomAD, n = 2,556), leave-gene-out CV.
- **Stage B** — filament-assembly phenotype (network vs aggregation) on a harmonised 297-variant desmin benchmark, leave-position/domain/study-out CV.

The paired-bootstrap AUROC contrast against AlphaMissense (BH-corrected across 19 pre-specified tests), the McNemar recalibration and the 618-variant DES VUS ranking used in the manuscript are all reproduced by `python ifclass.py train`.

## Install

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# GPU (optional but recommended for ESM-2): install torch for your CUDA before the line above
python test_ifclass.py            # → "all checks passed"
```

Needs ~16 GB RAM and ~6 GB disk. Tested on Python 3.11, Ubuntu 22.04.

## Reproduce

```bash
python ifclass.py download        # ClinVar, gnomAD, UniProt, AlphaFold, AlphaMissense (~2 GB, cached)
python make_family_profile.py     # 71-IF residue frequencies from vimentin alignment
python ifclass.py features        # ESM-2 embeddings + PCA-32 (GPU ~10 min, CPU ~1–2 h)
python ifclass.py train           # CV, paired bootstrap, McNemar, figures, VUS ranking
python audit_labels.py            # Supplementary Table S1 provenance audit
```

## Data (`data/`)

| File | What | Rows |
|---|---|---|
| `functional_labels.csv` | Curated DES assembly benchmark (network / aggregation) from 11 cell-transfection studies | 297 |
| `cross_IF_phenotypes.csv` | GFAP + NEFL assembly-phenotype variants for zero-shot cross-IF transfer | 39 |
| `external_test.csv` — Reserved for external validation; currently contains only the header and no variants. | 0 held-out DES variants for out-of-benchmark validation | 7 |
| `family_profile.csv` — Per-column residue frequencies across up to 71 aligned intermediate-filament proteins.
| `struct_burial.csv` | Vimentin 8RVE-derived interface-burial features mapped to DES | 469 |
| `label_conflicts.csv` | Excluded cross-study conflict | 1 |
| `label_disagreements.csv` | Two disputed dual-read entries (98.1% concordance overall) | 2 |

`functional_labels.csv` contains curated functional labels with gene, variant, phenotype, assay, source DOI, and study fields.

## Outputs (`results/`, generated by `ifclass.py train`)

- `metrics_stageA_*.csv`, `fig_roc_stageA.png` — pathogenicity leave-gene-out.
- `metrics_stageB_*.csv`, `fig_roc_stageB.png` — assembly phenotype under 3 CV schemes.
- `bootstrap_paired_deltas.csv` — 19 pre-specified paired contrasts, BH-corrected.
- `mcnemar_recalibration.csv` — recalibrated vs published-cutoff AlphaMissense (McNemar).
- `fig_importance.png`, `fig_heptad.png` — SHAP attribution; heptad × coil landscape.
- `ifclass_scores_DES.csv` — DES saturation map (618 VUS ranked).
- `ifclass_scores_all_IF_variants.parquet` — full release table.

## Known simplifications

- Heptad register uses one phase per coil segment; stutters are ignored. Swap in DeepCoil/CCHMM if reviewers ask.
- ESM-2 uses WT-marginal scoring. Masked-marginal is more accurate but costs L forward passes per protein.
- Interface burial is vimentin-8RVE-derived and mapped to desmin by BLOSUM62 alignment (median identity 0.64), not experimentally resolved on desmin.
