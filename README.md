# IF-FoldClass
IF-FoldClass. Cell-derived calibration of AlphaMissense for desmin filament-assembly variants. Two-stage LightGBM stacked with ESM-2. Stage A: pathogenicity across 20 IF genes (n=2556). Stage B: network vs aggregation on 297-variant DES benchmark. Paired-bootstrap AUROC, McNemar, 618 DES VUS ranked.
